# 确定地图交互、棋子控制与信息可见性

Parent: ../design-map.md
Labels: wayfinder:grilling
Type: grilling
Status: resolved
Assignee: Codex /root
Blocked by: none

## Question

探索和战斗时，玩家与 DM 分别可以如何移动棋子、查看地图与角色信息？如何处理共享控制、隐藏单位、迷雾、测距、地图切换以及误操作？首版支持到什么程度？

## Comments

- 用户已确认首版为上传二维地图图片、叠加方格，支持缩放、平移、测距和棋子吸附；网格尺寸、偏移及每格距离可配置。
- 用户已确认探索时可移动自己获准控制的棋子；战斗时仅当前行动单位可移动，DM 可临时放行或直接调整。首版显示移动距离，由 DM 裁定复杂移动。
- 用户明确要求后续自动判断本回合可移动距离，并提供指示提示。设计需预留移动路径、本回合已用距离、移动预算及剩余距离等信息；具体规则计算与提示样式尚未确定。
- 用户已确认首版由 DM 手动遮盖、揭露地图，全队共享已揭露区域；可单独隐藏敌人、机关等单位。
- 用户明确要求自动视野留到后续，加入后依旧保留 DM 手动遮盖地图及单独隐藏单位。设计解释：自动视野不得覆盖 DM 主动设置的区域遮盖或单位隐藏。
- 用户已确认敌人默认公开名称、头像、DM 允许公开的状态及生命概况，不公开精确生命值和完整资料；DM 可按单位调整公开字段。日志详情遵守同样的可见性约束。
- 用户已确认共享控制：默认控制自己的棋子，DM 可给一个棋子授权多名玩家并随时收回，操作记录保留实际操作者；回合限制按行动单位判断。
- 用户进一步要求一人多角：同一玩家可创建并控制至少两个独立角色及各自棋子，分别维护角色卡、生命与资源、回合位置；不将玩家账号与角色或棋子设计为一对一关系。
- 用户已确认队友默认查看战斗摘要，完整角色卡可按角色共享，DM 可查看完整角色卡。
- 用户已确认首版全团共用一张当前地图，由 DM 切换，其他地图与棋子位置存档；后续支持分队处于不同地图。
- 用户已确认首版仅提供团队笔记和 DM 备团资料，暂不提供玩家私人笔记。通用误操作纠正方式交由“确定手动裁定、未来自动结算与日志详情的统一流程”统一讨论。

## Answer

用户通过地图与权限两轮选择和笔记澄清确认：

1. 首版上传二维地图图片，使用可配置尺寸、偏移和距离的方格，支持缩放、平移、测距及棋子吸附。
2. 探索时玩家自由移动获准控制的棋子；战斗时按当前行动单位限制移动，DM 可放行或直接调整。首版提供距离显示、由 DM 裁定；后续加入本回合移动预算自动判定、剩余距离与范围指示，预留路径和已用距离信息，具体移动规则另议。
3. 首版全队共享 DM 手动揭露的地图；DM 可主动遮盖区域，单独隐藏敌人、机关等单位。自动视野留待后续，并不得覆盖 DM 主动设置的遮盖和隐藏。
4. 玩家账号与角色、棋子不是一对一关系。同一玩家可创建至少两个独立角色，各有角色卡、生命值、资源、地图棋子和回合身份。DM 可向多名玩家授予同一棋子的控制权并收回；日志记录实际操作者。
5. 敌人默认公开名称、头像、DM 允许的状态与生命概况，隐藏精确生命值及完整资料，DM 可逐单位调整；日志详情遵守对应可见性限制。
6. 队友默认查看战斗摘要，完整角色卡可按角色共享，DM 可查看完整角色卡。首版提供团队笔记和 DM 备团资料，不提供玩家私人笔记。
7. 首版全团使用 DM 指定的同一张当前地图，切换时保留其他地图及棋子状态；后续支持不同分队处于不同地图。
8. 移动与状态变更的误操作纠正纳入战斗与日志流程统一决定，不在本票单独假定撤销行为。
