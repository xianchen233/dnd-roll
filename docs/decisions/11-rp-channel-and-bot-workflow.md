# 确定 RP 文字频道、机器人操作与长期记录

Parent: ../design-map.md

Type: grilling
Status: resolved
Assignee: Codex /root
Blocked by: 03

## Question

首版如何集成代替现有 QQ 跑团机器人的文字发布、投骰与记录能力？明确角色发言和操作者身份、RP/OOC/战斗事件展示、命令支持、检索与导出、消息更正和长期保存，并决定是否需要 QQ 对接或历史记录导入。

## Comments

- 用户明确要求 RP 记录全部保留。语音开麦时也会把 RP 内容发送为文字，软件必须集成这项现有 QQ 群机器人的使用能力。
- 用户尚未要求内置语音、录音、自动转写、QQ 双向同步、兼容某个机器人全部指令或导入旧记录，不能擅自将这些记作首版需求。
- 用户已确认每日自动备份、默认保留最近 7 份，支持手动备份、下载和恢复。备份份数的轮换不得清理战役内的 RP 历史，完整备份与迁移须包含全部 RP 记录。

## Answer

1. 用户确认首版使用软件内文字频道与机器人能力，语音沿用现有工具，不接 QQ，不导入旧 QQ 历史。
2. 支持文字、图片与引用回复，区分角色 RP 和场外交流；消息修改保留历史版本，图片随记录持久保存和备份。
3. 用户同意表达式投骰、角色卡快捷检定、攻击与伤害投掷、当前发言/投骰角色切换，以及记录保存、检索、导出。按钮与命令共用权限和投骰逻辑；当前不承诺复刻旧机器人全部指令。
4. 用户新增首版自动初始先攻：战斗开始时系统自动投掷。产品流程为 DM 选参战单位及先攻配置、自动生成结果、DM 检查确认；不是每轮重投。一人多角分别参与，组别与平手保留确认。后续切换到 5R 基线后，投掷前加入突袭等适用配置，当前依据为 [核对 5R 2024 自动先攻及规则版本边界](13-research-initiative-2024.md)；2014 核验仅保留历史对照。
5. RP 长期全量保留，推荐同一时间线分类筛选，按场次归档、按角色与时间检索。实际账号、发言身份和当时名称分别记录。暗骰与隐藏资料按权限过滤，公开导出不能夹带 DM 记录。
6. 每日自动备份默认保留最近 7 份，但备份轮换不删除数据库里的 RP、相关图片、骰子、更正或战斗历史。完整迁移必须恢复这些关系，不能只恢复角色卡和地图。
7. 未来新机器人需求可增量补充。首版没有内置音视频、自动录音转写或玩家私人笔记。
