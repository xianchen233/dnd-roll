# 将设计规则基线切换为 5R 2024 加扩展

Parent: ../design-map.md
Labels: wayfinder:grilling
Type: grilling
Status: resolved
Assignee: Codex /root
Blocked by: 13

## Question

将原先“2014 为基础、选用新版内容”的设计切换为用户最新明确的“5R（2024 修订版）+ 扩展规则”，同步角色卡、规则搜索、先攻、模组依赖、自动化、验收与术语，保留历史决策但不再作为当前默认。

## Comments

- 用户已与同伴商量并明确要求此变更，毋须再询问规则基线。
- 本次只更新设计文档及决策记录，数据库选型、功能阶段与 DM 裁定原则继续沿用。

## Answer

1. 按用户明确指令，默认规则统一为 5R（2024 修订版）+ DM 选用的扩展，替代 2014 核心混用新版的初始选择。
2. 角色卡、规则检索、状态解释、先攻、模组目标体系、自动结算与验收均按当前基线更新。检索默认新版，同名旧版独立保留，扩展标明来源与适用版本，兼容性由 DM 确认。
3. 角色卡补齐物种、背景关联、起源专长和武器精通的记录入口，仍为半自动；自动先攻在投掷前配置突袭等因素，分组和平手保留确认，依据改用新版核验。
4. 2014 研究保留并标为历史对照，不再作为当前规则依据；旧扩展保留接入口但不自动声明兼容。规则体系与资料出版年份分别记录。
5. [设计方案 v0.2](../product-design.md)、词汇表、相关原决策与地图已同步。PostgreSQL、软件架构、RP 长期保存、备份及阶段划分沿用，不进入业务编码。
