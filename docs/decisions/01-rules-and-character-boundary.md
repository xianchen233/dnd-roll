# 确定混合规则与首版角色卡的支持边界

Parent: ../design-map.md
Labels: wayfinder:grilling
Type: grilling
Status: resolved
Assignee: Codex /root
Blocked by: none

## Question

以 5R（2024 修订版）为核心并引入扩展内容时，规则选择、冲突与例外由谁决定、作用于什么范围？首版角色卡保存哪些结构化数据，支持哪些手动或自动计算，如何标识内容来源和版本，并给后续自动结算保留可解释的依据？

## Comments

- 用户希望使用新版子职等新内容。
- 本票需区分“收录与展示内容”“辅助计算”“执行规则”，不能把内容存在推断为已经可自动执行。
- 用户已确认首版采用半自动角色卡：基础数值关联计算，能力和资源结构化记录，特殊能力与混合规则由 DM 裁定。计算依据可查看，DM 可覆盖计算值并记录原因；攻击自动结算留待后续阶段。
- 用户已确认内容准入采用 DM 管理，并要求提供自由开放开关。设计采用战役级“需要批准 / 自由选用”模式。该开关仅管理角色内容选用，不扩大棋子控制权或隐藏信息查看权。
- 用户已确认内容获取采用少量常用可搜索资料库，同时允许手动添加、保存、复制和复用自定义条目。角色可以引用资料库内容或保存 DM 定制版本；首版具体收录清单尚未决定。
- 内容来源、版本和本团选用情况分别记录，同名不同版本保留独立身份。内容收录不代表自动规则兼容或自动执行已经实现。
- 用户已确认：玩家可直接编辑自己的角色卡并留记录，DM 可查看和纠正；首版资源通过快捷按钮手动维护；切回审批模式保留已有配置，仅审批之后新增或替换的内容。
- 逐玩家独立覆盖内容准入权限只是助手提出的候选项，用户尚未要求或确认，不作为已定需求。

## Answer

用户通过两轮选择确认以下边界：

1. 首版采用半自动角色卡，基础数值可关联计算，能力与资源结构化保存，特殊能力和混合规则由 DM 裁定。计算值可查看来源，DM 可覆盖并注明原因；攻击自动结算留至后续阶段。
2. 当前核心基线为 5R（2024 修订版），允许 DM 选用扩展与定制内容。分别记录内容来源、适用规则体系、版本与本团选用情况，同名不同版本保留独立身份；旧版扩展需明确确认兼容性，不承诺自动兼容。
3. 战役级内容准入模式可切换“需要 DM 批准 / 自由选用”。仅管理角色内容选用，不影响棋子控制权、角色卡编辑权限或隐藏信息可见性。切回审批模式时保留已有配置，只对之后新增或替换的内容审批；提供现有角色内容检查入口。
4. 玩家可直接编辑自己的角色卡并留修改记录，DM 可查看和纠正。内容选用审批与日常角色卡编辑分开管理。
5. 资源消耗与恢复由快捷按钮手动维护，快捷掷骰本身不隐式扣资源。预留动作关联资源消耗的数据关系。
6. 内容获取采用少量常用可搜索资料库与自定义条目并行；条目可复制复用，角色可引用资料库内容或保存 DM 定制版本。
7. 本票确定能力边界。具体角色卡字段、首版资料库范围与计算清单转入“确定首版角色卡字段、计算清单与资料库收录范围”，不将尚未讨论的字段视为已定需求。
