# 确定手动裁定、未来自动结算与日志详情的统一流程

Parent: ../design-map.md
Labels: wayfinder:grilling
Type: grilling
Status: resolved
Assignee: Codex /root
Blocked by: 01, 02

## Question

一次行动从声明、掷骰、DM 裁定到应用状态如何流转？未来自动结算如何加入这条流程？日志如何解释依据、保存历史快照，并处理暗骰审批、公开摘要、撤销和纠正？

## Comments

- 用户对本票四个选择均回答 A，确认引导攻击、角色控制者结束回合、留痕更正，以及未来自动结算默认经 DM 确认。

## Answer

1. 首版攻击流程为：从角色卡选攻击、选目标、掷骰，DM 标记命中与否，再按需掷伤害并应用结果。目标、投掷与结果关联在同一行动记录中。首版不自动判定规则，资源继续由快捷按钮手动维护，掷骰不隐式扣除资源。
2. 当前角色的控制者可结束回合；DM 可随时跳过、调整顺序或切换行动单位。不设强制倒计时，一人多角按角色分别行动。
3. 错误通过关联原操作的更正记录修复，不删除原历史，不采用整场历史回退。记录实际操作者、受影响对象及变化。玩家仍可修改自己的角色卡并留痕；跨单位战斗结算纠正由 DM 处理。
4. 后续自动结算先生成预览与依据，由 DM 确认后应用；DM 可开启公开行动自动应用。暗骰始终先交 DM，由 DM 决定是否及何时应用与公开。
5. 战斗日志提供摘要和可展开详情，保存操作人、行动单位、目标、掷骰明细、修正值与来源、判定依据和状态前后变化。保留结算时的依据与相关数据，后续角色卡或内容更新不得改变旧日志的解释。手动裁定标记为 DM 裁定，不能伪装成自动规则计算。
6. 完整记录与面向玩家的可见内容分别管理：暗骰及隐藏字段仅 DM 可查，公开摘要不得带出隐藏骰值或敌人私密资料。DM 应用暗骰结果与公开其细节是独立选择。
7. 未来自动执行复用同一行动、待确认结果、应用结果和更正关系；自动效果与资源联动的具体范围由后续内容清单和阶段验收票限定。本票不承诺首版实现自动效果。
