# A06 movement evidence — 5R

Verified 2026-10-25 using dnd-rule-lookup: A locate-only resolved PHB2024
Movement and Position; B SRD 5.2 searched and fully read that page. Commercial
source text was not read/exported. Also checked the official
[SRD 5.2.1 PDF](https://media.dndbeyond.com/compendium-images/srd/5.2/SRD_CC_v5.2.1.pdf),
Playing the Game pp.14–15 and Rules Glossary Crawling/Climbing/Swimming/Speed.
Local translation: `Documents/SRD5.2_中文版/SRD5.2Chm-main/玩家手册2024/进行游戏/移动和位置.htm`.

Implementation interpretation: count every entered adjacent 5-foot square,
including diagonal steps; loops count repeatedly. Difficult terrain adds one
square, without stacking its causes. Crawling or climbing/swimming without a
special speed adds another square. Split moves retain spent movement. Distinct
special speeds require shared prior movement, not independent fresh budgets;
this slice deliberately leaves those exceptions to an explicit DM override.
The map does not represent walls/creature size/terrain/effects authoritatively,
so all cost figures require declared context and remain advisory.

The product chooses the standard 5-foot grid profile, not Euclidean distance or
alternating diagonal costs. Turn entry is the software ledger reset boundary;
grants do not manufacture a new speed allowance. DM adjustments are decisions,
not asserted SRD formulas. Extension automation coverage remains zero.
