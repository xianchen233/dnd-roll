# A12：普通匕首近战击昏支持矩阵

2026-10-27（Asia/Shanghai）。A07–A11保持；本包选自M3的其他武器击昏余项。
A索引仅定位玩家手册2024/进行游戏/生命值降至0点.htm，不读取商业正文。
B索引检索后完整回读SRD中文的同名页、进行游戏/临时生命值.htm和装备/武器.htm。
在线核对[官方SRD 5.2.1](https://media.dndbeyond.com/compendium-images/srd/5.2/SRD_CC_v5.2.1.pdf)
印刷p17击昏、p18临时生命、p89灵巧/轻型、p90投掷/迅击、p91匕首表。

| 项目 | 规则依据与软件支持 |
| --- | --- |
| 匕首身份 | 受信内置e1086d6d-e523-53d9-93b9-7aa24c718e39，1d4穿刺，STR或DEX。不能由名称、来源标签或伤害类型推断身份 |
| 使用方式 | 灵巧允许命中和伤害使用同一STR或DEX；投掷是远程攻击。本包必须明确KNOCK_OUT_MELEE；THROWN与MANUAL均不给候选 |
| 击昏 | 近战原伤害足以降至0时改留1HP并记录昏迷；不要求钝击。不是2014的0HP稳定 |
| 数值 | 先耗临时HP，原HP>0、伤害至少HP+tempHP；HP=1时损失0仍可记录。失手、免疫、不足、已有状态/死亡豁免、同源目标均人工 |
| 额外攻击和例外 | 无精通、无偷袭/毒药/魔法/轻型额外攻击/关联资源或其他未处理效果；DM审阅合法性及免疫/存活例外。不从自由文字自动识别 |
| 保存与应用 | 独立配置DAGGER-KNOCKOUT-V1、独立确认事件；确认不改卡，APPLY原子保存生命与来源化昏迷记录，保留骰、资源、原证据及旧门 |
| 后续 | 沿用A11人工处理短休、治疗/急救解除及昏迷关联规则；不自动执行完整状态，不自动公开 |

以上为概括及有意收窄的软件限制，不是完整规则正文。
