# P03 5R 角色卡依据（2026-10-20）

先使用工作区 `dnd-rule-lookup`：A 层仅 `--locate`；B 层 SRD 5.2 lex
定位并 `--read` 回读以下完整页，未读取/复制 A 层商业正文，未重建索引。
下面是公式和实现边界的改写，非完整规则转载。

| 字段/计算 | 已核对的 SRD 5.2 页 | 实现边界 |
| --- | --- | --- |
| 六属性调整值 | 玩家手册2024/进行游戏/六项属性.htm | floor((score−10)/2)，1–30，奇数负值向下取整 |
| 熟练加值 | 进行游戏/熟练.htm；创建角色/兼职.htm | 总等级1–20，2+floor((level−1)/4)，非各职业分别计算 |
| 技能/豁免 | 进行游戏/熟练.htm；创建角色/第五步：丰富细节.htm | 属性+熟练一次；技能专精2倍，豁免不提供专精选项；明确额外修正来源 |
| 被动察觉 | 创建角色/第五步：丰富细节.htm | 10+察觉；优势/劣势等情境由 sourced modifier 或 DM 覆盖表示，不猜状态效果 |
| 先攻/无甲AC | 同上 | 敏捷；10+敏捷；其他AC手填且保存来源，不叠多套AC公式 |
| 攻击/施法 | 同上 | 明确选择攻击属性；属性+熟练；伤害属性与额外加值；施法攻击=属性+熟练，DC=8+属性+熟练，多个施法来源分别算 |
| HP/生命骰/法术位 | 同上；创建角色/兼职.htm | HP最大值、生命骰种类与各池、法术位显式手填；不伪造完整升级/兼职法术位自动建卡 |
| 临时生命 | 进行游戏/临时生命值.htm | 与HP分开，不累加；明确替换选择，试投不消耗 |
| 死亡豁免 | 进行游戏/生命值降至0点.htm | 成功/失败分别0–3手动记录；不加属性、不自动掷骰或执行死亡 |
| 背景/起源 | 角色起源/背景详述.htm | 属性选择、起源专长、熟练与装备关联保留，最终属性不再重复加背景增益 |
| 武器精通/特性/状态 | 第五步：丰富细节及既有5R类别核验 | 保存实际选择和来源；状态持续时间来自手填效应，回合推进和移除由DM明确操作 |
