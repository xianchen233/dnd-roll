# 2014 先攻：规则核验与产品建议

核验日期：2026-10-18。适用版本：D&D 5e 2014；不用于证明 2024 或扩展能力。

状态：历史对照。用户已将软件基线改为 5R（2024 修订版）+ 扩展；当前核验见 [5R 规则基线核验](initiative-2024.md)。以下结论不再作为本项目默认行为的依据。

## 已核验的基础规则

- 战斗开始时，参战者进行敏捷检定确定先攻，按总值从高到低行动；不是每轮重新投掷。[官方 Basic Rules 2014：Combat / Initiative](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/combat)
- 同一种生物组成的组，由 DM 为整组投一次先攻，组内成员在同一时机行动。[同上](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/combat)
- 平手时，DM 决定其控制单位之间的次序，玩家决定其角色之间的次序；怪物与玩家角色平手可由 DM 决定。规则另提供平手者再投 d20 决序的可选办法。[同上](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/combat)

## 建议产品默认值（设计建议，不是额外规则）

- DM 选择参战单位、确认隐藏单位和分组，点击“开始战斗”后，由服务端自动生成首次先攻。
- 按角色／参战单位生成结果，一名玩家控制两个角色时分别处理；同怪组由 DM 显式配置，不能只凭相同名称自动合并。
- 基础骰式采用 `1d20 + 敏捷调整值`；角色已配置的额外先攻修正列明来源，混用版本和未支持的特殊能力由 DM 确认或覆盖。
- 平手先标记“待定序”，提供拖动排序，DM 确认后开始首个回合；不悄悄以敏捷高低或 ID 冒充基础规则。
- 后续轮次保持顺序，手动修改、重投与战中加入单位均保留操作日志。重连和重启恢复已有结果，不重投。
- 先攻日志关联骰子、修正来源和 DM 更正。隐藏单位的存在、组别、先攻及内部条目都只发给 DM，玩家可见列表不能暴露占位空档。此项承接既定产品权限，不是先攻规则本身。
